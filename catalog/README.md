# 比划猜词公开词库

供比划猜词安卓应用匿名读取的已发布词库。仓库写入权限由所有者管理，手机无需 GitHub 登录或访问令牌。

词库地址：https://raw.githubusercontent.com/dz333/Bobbyboring/main/catalog/manifest.json

当前 v4：24 个主题，2409 条词条。歌名、电影名、明星名字各 103 条。

本次新增：

- 歌名：但愿人长久、一剪梅、橄榄树。
- 电影名：秋菊打官司、一个都不能少、蓝色大门。
- 明星名字：蒋雯丽、陈道明、濮存昕。

安卓应用“设置 → 词库更新”中保存上述来源，再点击“检查词库更新”。成功应显示 v4、2409 条。打开应用时会自动检查，15 分钟内不重复；断网继续使用最近有效缓存。

已在电脑上使用应用实际的 Java 下载及解析代码，成功读取线上 manifest 与 release 并校验 SHA-256、长度、格式和词条数；安卓真机和实际玩家网络仍需验证。

发布者先上传不可变的 releases/<sha256>.json，再更新 manifest.json。不要直接修改 release 或只改词条而不重算摘要和长度。发布版本必须递增。完整生成与校验工具位于本地安卓源码包 tools/export-catalog.py、tools/check-catalog.sh。

旧 Sites 后台的发布不会同步至此仓库。目前使用文件发布流程，网页编辑后台尚未迁移。这里不存储个人词卡、战绩、账号授权令牌或签名密钥。
