# 比划猜词公开词库

供安卓应用匿名下载的已发布词库。仓库写入由所有者管理，手机无需 GitHub 账号或令牌。

词库地址：https://raw.githubusercontent.com/dz333/Bobbyboring/main/catalog/manifest.json

当前 v5：24 个分类，每类 220 条，共 5280 条分类词条；随机混合按文字去重后有 5191 个不同词。原 v4 的 2409 条分类词条全部保留，每个分类均超过原数量的两倍。

应用 1.2.0 内置同样的扩充词库，断网也能使用，并新增最近 5 局跨分类出词去重。出示即记入本机，包括答对、跳过和没有作答的最后一张。记录正常重启后保留。可用词暂时出完时提示换分类，不会自动重复近期词；玩家可在设置中主动重置近期出词记录。

旧版 1.1.2 能通过在线更新取得扩充词库，但跨局去重必须覆盖安装新版 1.2.0。安装包和源码由开发聊天交付。

已使用应用生产 Java 代码真实下载并校验 v5 的 SHA-256、长度、格式和数量；新版也经过 Android 15 模拟器的旧版覆盖升级、连续游戏和重启记录测试。实际手机的显示与传感器表现仍需玩家验证。

发布时先上传 releases/<sha256>.json，再更新 manifest.json；保持原始字节，每次递增词库版本。不要只修改词条而不重算摘要和长度。生成与校验工具在本地安卓源码 tools/export-catalog.py、tools/check-catalog.sh 中。

后续直接编辑 online-catalog/source.json。tools/expand-catalog.py 只用于复现本次 v4 到 v5 的整理，不是日常发布步骤。

旧 Sites 网页后台的发布不会同步到本仓库。这里不存储玩家战绩、个人词卡、近期出词记录、账号凭据或签名密钥。
